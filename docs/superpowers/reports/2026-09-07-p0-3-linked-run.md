# P0.3 — linked runner preflight

**Datum:** 7. 9. 2026

**Stav:** blokováno před připojením

## Co bylo spuštěno

Byl spuštěn nový runner v read-only režimu s project refem nalezeným v lokální
Supabase CLI konfiguraci původního checkoutu. Hodnota project refu není v tomto
reportu uvedena.

Příkaz:

```text
npm run verify:linked-security
```

## Sanitizovaný výstup

```json
{
  "status": "failed",
  "failureCode": "MISSING_SUPABASE_ACCESS_TOKEN",
  "target": "linked-sandbox",
  "mode": "read-only"
}
```

## Význam výsledku

Runner nenašel `SUPABASE_ACCESS_TOKEN` v procesu, uživatelském ani systémovém
environmentu. Skončil před síťovým spojením a nepoužil existující CLI session,
`SUPABASE_SECRET_KEY` ani `SUPABASE_SERVICE_ROLE_KEY`.

Nebyla spuštěna migrace, SQL zápis, pgTAP write test, reset databáze ani změna
linked sandboxu.

## Co tento report dokazuje

- chybějící credential vede k bezpečné a srozumitelné chybě,
- token ani project ref se nevypisují,
- read-only runner nepoužije aplikační service-role credential jako fallback.

## Co tento report nedokazuje

Toto není skutečný linked databázový důkaz. Databázový dotaz se kvůli chybějící
runner identitě vůbec neprovedl. P0.3 zůstává otevřené do běhu se samostatným
scoped tokenem omezeným na linked sandbox.
