# Velocity CRM

Provozní CRM pro call centrum. Přehled produktu, prostředí, aktuálních ověření a otevřené práce je v [projektovém průvodci](docs/PROJECT.md). Pravidla pro práci v repozitáři jsou v [AGENTS.md](AGENTS.md).

Před spuštěním nebo změnou databáze vždy ověř cílové prostředí podle projektového průvodce. Produkční prostředí je `https://velocity.majkito.com`; testovací prostředí je `https://dev.majkito.com`.
